# 可复刻共享层与站点独立层

本仓库可作为新站的起点，但复刻发生在创建新仓库时。站点之间不得跨站运行时依赖：不从另一个站点导入源码、读取其内容配置、调用其内部 API，也不共享发布状态。修复或改进应在确认适用后分别同步到各仓库。

## 可复刻共享层

- Astro 静态内容路由与 React 交互岛的结构。
- `WatermarkProvider` 接口，以及服务端任务、上传校验和私有对象存储的边界。
- Pages CMS 字段组织方式、站点初始化器和配置校验方式。
- 单元测试、Playwright 独立服务、CI 和发布前质量门。
- 安全头、秘密不进入浏览器、日志不输出签名 URL 等通用约束。

共享的是代码模式和测试契约，不是线上服务实例或站点数据。需要同步共享层改进时，应以独立提交复制并在目标站完整验证。

## 站点独立层

下列信息必须由每个仓库独立配置和维护：

- 品牌、文案与媒体，包括 Logo、页面内容、FAQ、博客、法律说明、CTA 和 CMS 内容值。
- 域名与 OAuth 回调，包括 canonical URL、Better Auth 基础地址、Google 客户端及授权回调。
- Vercel 项目、环境变量、部署记录和生产验证。
- Pages CMS 仓库/分支设置、Google Analytics 标识及其他第三方控制台配置。
- R2 凭据、CORS 来源、对象命名空间和生命周期策略；只有在明确批准后才可共享云账户或 bucket。

## 复刻检查

1. 从模板创建独立仓库，不添加指向原站源码或内容的运行时依赖。
2. 用 `site.config.json` 和 `npm run site:init -- site.config.json --apply` 生成站点专属配置。
3. 单独检查品牌、内容、媒体、域名、回调、分析标识、CMS 与云资源。
4. 运行 `npm run site:validate` 和 `npm run verify`，并在目标站自己的预览与生产环境完成验证。
